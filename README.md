# Vitrine — Landing

Landing page da Vitrine em **HTML/CSS puro**, sem framework nem build. Protótipo
de demonstração.

```
index.html    a página inteira
estilos.css   folha única, dirigida por variáveis CSS (mesmos tokens do dashboard)
```

Abrir é só abrir o `index.html` no navegador (ou servir a pasta com qualquer
servidor estático). Não há passo de build.
